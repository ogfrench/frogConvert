# Visual reasoning: explanation before decoration

Decide what relationship, pattern, experience or choice the audience needs to see. A layout is successful when it makes that information easier to grasp without distorting it. Master slides and templates are examples, not a whitelist.

| Communication question | Useful form | Common misstep |
| --- | --- | --- |
| Compare quantities | Common-scale bars, dot plots, compact value comparison | Separate gauges or unrelated scales |
| Show change over time | Time series, slope chart, small multiples | Missing periods or a manipulated interval |
| Show distribution or composition | Histogram, stacked bars, distribution plot | Donuts without meaningful part-to-whole context |
| Test an association | Scatter plot with clear axes and context | Causal claim from correlation |
| Explain a mechanism | Sequence, flow, state diagram | Three decorative cards labeled as a process |
| Compare alternatives | Trade-off table or meaningful matrix | Arbitrary axes and unlabeled criteria |
| Show a place-based pattern | Map, when geography truly changes the answer | Map used as ornament |
| Show a human experience | Real observed journey, relevant licensed image or sourced quotation | Stock photography presented as evidence |
| Present a single essential statement | Precise type, appropriate space | Icons, numbers and gradients added to fill space |

A table is often preferable when exact values matter more than shape. Make data labels, units, baselines and scope legible. A bar chart generally needs a defensible zero baseline; line charts need meaningful labeled scales. Explicitly qualify important uncertainty.

## Annotated alternatives (fictional)

**Same data, weaker treatment:** Two pilot cohorts completed 18/25 and 14/25 tasks. A dashboard with oversized green and blue score rings and a "16% performance boost" headline looks polished but misstates the arithmetic and implies causality.

**Same data, stronger treatment:** Two common-scale bars labeled "18 of 25 (72%)" and "14 of 25 (56%)", with cohort names and a short caveat on comparability. Title: "Completion differed between the observed cohorts." No "uplift" claim until a valid study supports it.

**Same process, weaker treatment:** A three-card layout ("Discover / Enable / Deliver") with unrelated icons and generic benefits.

**Same process, stronger treatment:** A concise sequence showing intake, eligibility review and decision, with both actual approval handoffs visible. Annotate duration only if measured. A custom composition may be needed; do not invent timing to populate a template.

## Composition, imagery and motion

Use hierarchy, focal points, type contrast and space to guide attention to the content. Repetition helps direct comparisons; variation helps distinct ideas. Preserve legitimate brand signatures and useful density. Don't automatically add a badge, decorative KPI, eyebrow, glow, rounded card or emphasized phrase to every slide.

Use supplied photography when relevant. A stock collaboration image is not evidence of user research or the client's team. Verify rights, subjects and implied endorsements. Motion is useful when it reveals sequence, cause or transformation; the point must remain understandable when paused, printed or exported.

Inspect the output at realistic presentation size when a renderer is available. Fix clipping, bad axes, weak hierarchy, unreadable labels, poor crop and title/evidence mismatches. An HTML build or PPTX file existing does not, by itself, prove fidelity.
