---
name: inspect-formats
description: Check which file formats and conversion routes frogConvert supports in the local environment.
---

Use `list_formats` to inspect currently available formats and `find_conversion_path` to check a particular route. Availability varies by installed native tools and browser-bridge support. Explain missing dependencies accurately and do not promise that every browser conversion works in the local MCP server.

This skill is for discovery; never transform files unless the user requests conversion or editing.
